## 📚 O que aprendi com este desafio

Este desafio reforçou aprendizados importantes:

- A IA não substitui o pensamento humano, ela **potencializa decisões**
- Um bom prompt define a qualidade da solução
- Pensar como produto é tão importante quanto pensar como código
- Documentar bem um projeto é um diferencial no mercado
- Clareza de ideia vale mais do que complexidade técnica

Além disso, ficou claro como o uso estratégico de IA pode acelerar a criação de soluções reais e viáveis.
